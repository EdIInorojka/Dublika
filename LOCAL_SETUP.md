# Дублика — локальный MVP

Рабочая версия запускается на этом компьютере и слушает только `127.0.0.1`. Исходники, записи и готовые ролики остаются в папке `.local-data` и не отправляются на публичный сайт.

## Первый запуск

```powershell
npm install
npm run setup:media
npm run local
```

После запуска откройте [http://localhost:8788](http://localhost:8788).

Если интерфейс открыт с Vercel, разрешите его точный адрес при запуске локального сервера:

```powershell
$env:DUBLIKA_ALLOWED_ORIGINS = 'https://адрес-деплоя.vercel.app'
npm run local
```

Клиент с Vercel будет обрабатывать файлы на этом компьютере через `127.0.0.1:8788`; медиаданные не сохраняются в Vercel.

## Что уже работает

- загрузка MP4, MOV, WebM, MKV и M4V размером до 1 ГБ;
- импорт прямой ссылки, YouTube и VK Видео;
- выбор фрагмента продолжительностью до 4 минут;
- разбиение фраз на удобные для записи окна по 2–4 секунды; паузы и знаки конца фразы используются как приоритетные границы;
- запись микрофона по репликам с живым индикатором громкости и транскрипцией;
- автоматическая остановка записи точно по длительности реплики;
- управляемое прослушивание без одновременного запуска нескольких отрывков;
- очистка и нормализация голоса, приглушение исходной дорожки под дублем;
- вшивание отредактированных субтитров и сборка H.264/AAC MP4;
- локальный вход по коду и три пробных рендера на устройство.

## Автоматическое распознавание текста

Для автоматической русской расшифровки нужен ключ Deepgram: сервер передаёт только выделенный пользователем фрагмент в Deepgram Nova-3 (`ru`), получает таймкоды слов и смысловые фразы, затем собирает из них реплики по 2–4 секунды. В запросе включены `smart_format`, `utterances` и отказ от Model Improvement Program. Без ключа приложение **не выдумывает субтитры**: оно создаёт пустые таймированные окна по реальной звуковой дорожке, в которые можно вписать сценарий вручную.

```powershell
$env:DEEPGRAM_API_KEY = 'ваш_ключ'
npm run local
```

## Границы MVP

Экран тарифов готов, но реальное списание денег намеренно не имитируется: для коммерческого запуска нужны ключи и вебхуки ЮKassa или CloudPayments. Telegram/OAuth также требуют зарегистрированных приложений и их секретов. Публичный доступ к этому компьютеру следует открывать только через HTTPS-прокси с авторизацией; сам медиасервер специально не выставлен в локальную сеть.
